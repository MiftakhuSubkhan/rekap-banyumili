📖 Panduan Sambung Google Sheets

Ikuti 4 langkah cepat ini untuk membuat spreadsheet online gratis Anda:

  1. Buka Google Sheets baru di sheets.new
  2. Klik menu Ekstensi (Extensions) ➔ Apps Script.
  3. Hapus isi bawaannya, lalu salin dan tempel kode dari file google_apps_script.js di project Anda.
  4. Klik tombol biru Terapkan (Deploy) ➔ Penerapan baru (New deployment):
    • Pilih jenis: Aplikasi Web (Web app)
    • Akses (Who has access): Pilih Siapa saja (Anyone)
  5. Salin URL Aplikasi Web yang dihasilkan (berakhiran /exec), lalu tempelkan di kotak URL di atas dan klik 💾 Sambungkan!
